# 공부방 — versão app (PWA)

App de estudo de coreano 세종한국어 2A. Funciona no telemóvel como uma app: ícone no ecrã principal, ecrã inteiro e funciona sem internet.

## Publicar no GitHub Pages
1. Em github.com, cria um repositório novo (por exemplo `gongbubang`), público.
2. "Add file" › "Upload files" e envia todos os ficheiros desta pasta (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`).
3. "Settings" › "Pages" › em "Branch" escolhe `main` e `/ (root)` › "Save".
4. Passado um minuto, a app fica em `https://O-TEU-UTILIZADOR.github.io/gongbubang/`.

## Instalar no telemóvel
- Android (Chrome): abre o link › menu ⋮ › "Instalar app" ou "Adicionar ao ecrã principal".
- iPhone (Safari): abre o link › Partilhar › "Adicionar ao ecrã principal".

## Diferenças em relação ao claude.ai
- Fora do claude.ai não há Claude: a correção de escrita, a conversa, a avaliação do 말하기 e os textos gerados mostram a resposta-modelo ou um aviso.
- O progresso fica guardado no telemóvel, separado do progresso no claude.ai.
